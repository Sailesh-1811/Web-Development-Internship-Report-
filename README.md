# 🌐 Personal Portfolio Website

A responsive and interactive **Personal Portfolio Website** developed as part of my **Web Development Internship at Wiztech Automation Solutions, Anna Nagar, Chennai**.

The portfolio is designed to showcase my **education, technical skills, projects, certifications, resume, and contact information** in a professional and organised manner.

## 🚀 Live Website

🔗 **[View My Portfolio](https://sailesh-1811.github.io/Sailesh-S-s-portfolio/)**

## 📌 Project Overview

This project was developed during my Web Development Internship from **1st August 2026 to 17th August 2026**.

The main objective was to gain practical experience in web development and apply HTML, CSS, and JavaScript concepts to build a functional and responsive personal portfolio website.

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, responsiveness, and visual design
* **JavaScript** – Interactive features and user interaction
* **Visual Studio Code** – Development environment
* **GitHub** – Version control and project repository
* **GitHub Pages** – Website deployment and hosting

## ✨ Features

* 🏠 Home section
* 👨‍💻 About Me section
* 🎓 Education details
* 💻 Technical Skills
* 📂 Projects showcase
* 🏆 Certificates and achievements
